# Unplug Alarm

macOS menu-bar app: arm it while the charger is connected; pulling the cable plays a loud
looping alarm at full volume until you disarm with Touch ID or your password.

Pair it with Amphetamine (closed-display mode) so the Mac stays awake with the lid shut.

## Run

```sh
swift run
```

Requires macOS 15+ and Swift 6.2+.
